# SybilShield

Staked cross platform credential and anti sybil trust graph passport, built as a
GenLayer Intelligent Contract with a React dashboard.

SybilShield turns a social handle into an on chain passport backed by real
staked SST, peer trust attestations, and a validator consensus review of the
public proof page. Every credential decision is made by live validators reading
the evidence. There is no owner key, no admin override, and no deterministic
shortcut that can mint a badge or move escrowed funds.

The full documentation, the deployed studionet address, and the four way
verification record land with the first deployment milestone. See
[docs/evidence.md](docs/evidence.md) for the transaction level record.
