# Identity proof: orion_labs

This page is the public identity proof for the handle `orion_labs` on GitHub. It
is mirrored from the account profile and describes the operating history of the
account.

- Handle: `orion_labs`
- Domain: `GITHUB`
- Key type: ed25519, rotated 2025-11-02

The account publishes protocol research notes and maintains two public
repositories. The profile page lists the contribution graph, the verified commit
history, and the organization membership.

This page intentionally does not publish an identity fingerprint. It exists to
demonstrate the fail closed path of the SybilShield credential verification: when
the claimed handle is visible but the fingerprint is not bound to the page, the
passport stays UNVERIFIED_PROVISIONAL and the staked SST remains locked in vault
custody.

The account owner has been asked to publish the fingerprint in a signed commit
before requesting another verification round.
