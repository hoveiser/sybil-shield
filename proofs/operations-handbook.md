# Distributed team operations handbook

This page is a general landing page about operating procedures for distributed
teams. It covers incident response checklists, release cadence, and on call
rotation policy.

It does not name any individual account, it does not publish a signing key, and
it does not contain an identity fingerprint. It is intentionally unrelated to the
credential claim that points at it.

The purpose of this page is to show what happens when a claim is backed by
evidence that never references the claim at all. The deterministic pre check
fails, the authenticity anchor drops to zero, and the passport is slashed. The
slashed stake leaves vault custody only when the settlement is finalized and
claimed.

Nothing on this page should be read as an endorsement of any identity claim.
